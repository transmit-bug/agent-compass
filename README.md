# agent-compass

A series of skills for **context engineering** — helping AI agents understand project structure, navigate codebases, and follow project conventions.

## Skills

| Skill | Description |
|-------|-------------|
| [multi-agentsmd](./multi-agentsmd/) | Generate layered AGENTS.md for structured projects with sub-directories |
| [multi-agentsmd-rules](./multi-agentsmd-rules/) | Add user-defined rules and constraints to AGENTS.md |
| [create-agentsmd](./create-agentsmd/) | Generate a root AGENTS.md for any repository |

## Philosophy

> **Write what would confuse an agent, skip what wouldn't.**

Each skill focuses on a specific aspect of building agent-readable project context — from high-level architecture to directory-level conventions to user-defined guardrails.

## Installation

```bash
pi skill install agent-compass/multi-agentsmd
```
